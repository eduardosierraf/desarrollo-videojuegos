Física

Rigidbody

Sin Rigidbody

El cubo no se mueve — no hay física aplicada sobre el objeto.

Con Rigidbody

La gravedad lo afecta: el cubo cae de forma realista.

Inspector → Add Component → Rigidbody

Fundamentos

Vectores: Vector3(x, y, z)

XDerecha / Izquierda
YArriba / Abajo
ZAdelante / Atrás

Vector3(1, 0, 0) → derecha · Vector3(0, 1, 0) → arriba · Vector3(0, 0, -1) → atrás

La física del movimiento

La ecuación del movimiento

d = v × t
dDistancia
vVelocidad · unid./seg
tTiempo · segundos

Si v = 5 y t = 2s → d = 5 × 2 = 10

Entrada del jugador

Input: Legacy vs Input System

Sistema viejo

Input Legacy

Input.GetAxis("Horizontal") y GetKeyDown(KeyCode.Space). Solo teclado y mouse, configuración fija.

Sistema nuevo

Input System

InputSystem.actions.FindAction("Move").ReadValue<Vector2>(). Gamepad, táctil y rebinding en tiempo real.

Consistencia

Sin Time.deltaTime, el juego se mueve distinto según los FPS de cada computador.

  1. 01Sin deltaTime60 FPS = 60 movimientos/seg · 30 FPS = 30 movimientos/seg
  2. 02Con deltaTimeMovimiento uniforme, sin importar los FPS
transform.Translate(dir * velocidad * Time.deltaTime);
Script completo · Legacy

Movimiento.cs — Legacy

using UnityEngine; public class Movimiento : MonoBehaviour { public float velocidad = 5f; public float fuerzaSalto = 5f; private Rigidbody rb; void Start() { rb = GetComponent<Rigidbody>(); } void Update() { float h = Input.GetAxis("Horizontal"); float v = Input.GetAxis("Vertical"); Vector3 dir = new Vector3(h, 0, v); transform.Translate(dir * velocidad * Time.deltaTime); // Salto if (Input.GetKeyDown(KeyCode.Space)) { rb.AddForce(Vector3.up * fuerzaSalto, ForceMode.Impulse); } } }
Script completo · Input System

Movimiento.cs — Input System

using UnityEngine; using UnityEngine.InputSystem; public class Movimiento : MonoBehaviour { public float velocidad = 5f; public float fuerzaSalto = 5f; private Rigidbody rb; private InputAction moveAction; private InputAction jumpAction; void Start() { rb = GetComponent<Rigidbody>(); moveAction = InputSystem.actions.FindAction("Move"); jumpAction = InputSystem.actions.FindAction("Jump"); } void Update() { Vector2 moveValue = moveAction.ReadValue<Vector2>(); Vector3 dir = new Vector3(moveValue.x, 0, moveValue.y); transform.Translate(dir * velocidad * Time.deltaTime); // Salto if (jumpAction.WasPressedThisFrame()) { rb.AddForce(Vector3.up * fuerzaSalto, ForceMode.Impulse); } } }
